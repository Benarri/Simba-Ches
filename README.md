# Simba Chess

First static homepage preview for Simba Chess.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your public `simba-chess` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish. The address is usually `https://YOUR-USERNAME.github.io/simba-chess/`.

This is a static preview. Authentication, real chess matches, persistent data, real rankings, tournaments and chat still need to be implemented and connected to a backend.
